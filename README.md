## 🚀 What I Build

- 🎬 **AIGC pipelines**：圖片、影片、語音和 TTS 的生成管線。串接多家生成模型，用 ComfyUI 組工作流，在雲端 GPU 上跑批次推論
- 🤖 **AI agents**：用 Claude Code、MCP、skills 和 subagents 組成多代理工作流，處理研究、寫程式、內容產製、SEO 文章，甚至自己試玩遊戲並整理成設計文件
- 💬 **Social media bots & automation**：多平台（Facebook、Instagram、LINE、Telegram、Threads）的 AI 客服與自動發文系統，搭配 LangGraph RAG 知識庫
- 🧱 **Full-stack AI SaaS**：FastAPI + React + Docker 的多租戶產品，有點數計費和金流串接，從後端到前端一手包辦
- 📈 **Trend analytics & data pipelines**：追蹤短影音平台上表現異常好的爆紅內容，以及用 LLM 自動摘要的電子報管線
- 🔎 **RAG & multimodal search**：例如 [SemSearch](https://github.com/a303990366/semsearch)，用一句話找到電腦裡的照片、PDF、錄音和影片，全部在本機執行（EmbeddingGemma 2）
- 🧩 **Also**：Chrome 擴充功能、瀏覽器與手機自動化、在 Modal 雲端 GPU 上微調 LLM
